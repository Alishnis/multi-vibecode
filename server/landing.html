From setup to your first session

One command.
Then just build.

Pick a team room and open Terminal in your project folder. The guided setup installs the client, checks your tools, helps connect GitHub, and opens your workspace.

Python 3 and curl are required. Setup can install Claude Code for you. GitHub sign-in and agent permissions remain in your control.

Already connected? Open your team room →
Open room ↗
For your next session: python3 coord/team.py --action work. Shared decisions and file activity are visible to people who know your room code. Code changes may be sent for AI summaries; turn that off with ai_summary: false.


Will it overwrite my work?
Automatic sync updates clean shared branches only. Task branches, unsaved edits, and diverged history are left for you to resolve.
Can I keep using my terminal?
Yes. Team Contract installs hooks and an agent connection in your project. The workspace launcher brings them together; the action menu is there when you need it.
