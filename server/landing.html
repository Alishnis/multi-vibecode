what team contract does for your team

agents warn each other

a heads-up before the edit, not after the merge

when an agent is about to change a file, it asks the room first. the answer says which kind of overlap it is, so the agent knows what to do next.

  • active collisiona teammate changed it minutes ago and is still working
  • outdated readtheir change is in your copy, but your agent read the file before it
  • another checkouttheir change lives only on their computer
  • claimeda teammate announced they are about to edit it
  • recent edita note, never a stop

agents claim work

the first claim wins

before its first edit, an agent says what it is about to do and which files it needs. a second claim on the same files is refused, so nobody builds on sand.

  • release any time

questions teams ask

    

      
will it overwrite my work?
no. syncing only updates a clean shared branch. task branches, unsaved edits and diverged history are left alone, and the notice says why.

      
what if two people need the same file?
the first claim wins and the second agent is told who owns it. agree who changes which part, ask the owner to release, or wait: claims run out by themselves.

      
do i need an account?
not for the room. you only sign in to github, with your own login, to share and sync code. the team key for settling conflicts is a password your team sets once.

      
does it work outside claude code?
the hooks and tools are built for claude code today. shell commands and other editors are not watched, so keep using git for those.
